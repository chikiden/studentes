Makefile — скрипт автоматической компиляции.

Реализованный функционал
Автоматизация сборки Makefile, создание статической .a и динамической .so библиотек
Линковка времени выполнения — динамическая загрузка функций через системные вызовы POSIX dlopen и dlsym (main_dynamic)
Структуры данных: динамический Стек (Undo/Redo), Очередь (каскадное удаление) и Связный список для хранения базы
Работа с файлами через системные дескрипторы Linux (open, read, write, lseek) с ограничением прав доступа 0644
Рекурсивный обход каталогов с помощью функций POSIX (opendir, readdir) для поиска резервных копий базы данных
make

# Запуск статической сборки
./app_static

# Запуск динамической сборки (rpath настроен внутри Makefile, так что подхватится сразу)
./app_shared

# Запуск версии с dlopen
./app_runtime
